# Equipe-3-Experimentação

**Este repositório contém dois sistemas desenvolvidos em Python para simular operações de uma lanchonete.

O **Boca Feliz** é um sistema de gerenciamento de pedidos e controle de estoque, responsável por verificar a disponibilidade dos ingredientes, processar pedidos e atualizar as quantidades armazenadas.

O **Sistema de Gerenciamento de Filas** permite cadastrar clientes, organizar a ordem de atendimento, consultar o próximo cliente, verificar a quantidade de pessoas na fila e remover registros.

Ambos os sistemas possuem defeitos introduzidos intencionalmente e serão utilizados em um experimento acadêmico de Engenharia de Software, com o objetivo de comparar a identificação e correção de problemas de programação com e sem o auxílio de Inteligência Artificial.
